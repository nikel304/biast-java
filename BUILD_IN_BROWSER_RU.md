# Сборка BIAST в браузере через GitHub Actions

1. Создай репозиторий на https://github.com/new (например, `biast-minecraft`).
2. Распакуй ZIP на компьютере. Загрузи **содержимое** папки `biast_minecraft_forge_1_20_1` в корень репозитория. Важно: папка `.github/workflows` тоже должна попасть в репозиторий.
3. На GitHub открой вкладку **Actions** и разреши GitHub Actions, если GitHub попросит.
4. Выбери workflow **Build BIAST Forge mod** и нажми **Run workflow**. Также сборка запускается при push в ветку `main`.
5. Дождись зелёной галочки. Открой завершённый запуск workflow, найди раздел **Artifacts** и скачай `biast-forge-1.20.1`.
6. Распакуй скачанный artifact ZIP. Файл `.jar` положи в `.minecraft/mods`.

Требования для игры: Minecraft 1.20.1, Forge 47.2.0, Java 17. Убедись, что остальные моды совместимы.

Если workflow завершился ошибкой, открой его лог и пришли сюда текст ошибки — по нему можно исправить проект. Сам факт добавления workflow не гарантирует успешную сборку: её нужно запустить на GitHub.
